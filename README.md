# 陶艺展览策划台

面向独立策展人的 Vue 3 展览编排工具。首屏直接进入策展工作面：创建展览草稿、选择作品并上线展览状态。

## 使用

```bash
npm install
npm run dev
npm run build
npm run verify
```

`npm run verify` 通过 Vite SSR 在 Node 中执行校验、原子性、隔离性、刷新恢复与 UI 渲染烟囱检查。

## 工作流

1. 创建展览：校验名称非空，创建草稿并选中。
2. 编辑信息：在策展工作面修改副标题、策展人、开放日期、结束日期与说明并保存。五项必填、结束日期不得早于开放日期；校验失败会提示原因且不写入数据。
3. 编排作品：切换作品加入状态，实时更新并持久化（编辑信息不会改动作品编排）。
4. 上线展览：上线前检查至少一件作品，成功后状态转为“已上线”，失败显示原因。

## 信息生效规则

信息保存后**立即生效**：列表、策展详情、观众导览与分享弹层始终读取同一份展览数据，不存在待发布副本，因此观众与策展人看到的永远是同一版本；已上线展览保存修改后即时对观众可见（编辑面板会明确提示）。刷新页面后从 `localStorage` 恢复修改。

数据保存在浏览器 `pottery-exhibit-studio-v1` 命名空间，编辑只作用于当前展览，不影响其他展览及其作品编排。
