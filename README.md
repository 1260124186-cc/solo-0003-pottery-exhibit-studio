# 陶艺展览策划台

面向独立策展人的 Vue 3 展览编排工具。首屏直接进入策展工作面：创建展览草稿、选择作品并上线展览状态。

## 使用

```bash
npm install
npm run dev
npm run build
npm run smoke   # 空间编排工作流烟囱检查
```

数据保存在浏览器 `pottery-exhibit-studio-v1` 命名空间。策展工作面分「作品编排」与「空间编排」两个视图：后者为展览内每件作品记录展厅、墙面位置与建议停留分钟，支持上移下移调整呈现顺序，随展览一并持久化并在刷新后原样恢复。当前为初始化基线，测试将在后续任务中补充；构建命令覆盖各工作流的生产烟囱检查。
