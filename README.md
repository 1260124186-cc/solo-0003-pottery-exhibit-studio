# 陶艺展览策划台

面向独立策展人的 Vue 3 展览编排工具。首屏直接进入策展工作面：创建展览草稿、选择作品并上线展览状态。

## 使用

```bash
npm install
npm run dev
npm run build
```

数据保存在浏览器 `pottery-exhibit-studio-v1` 命名空间。当前为初始化基线，测试将在后续任务中补充；构建命令覆盖三个工作流的生产烟囱检查。

## 导入展览资料

左栏选择此前导出的 JSON 文件即可批量恢复（或追加）展览与作品。文件顶层需为包含 `exhibitions` 与 `artworks` 两个数组的对象。

- **逐条校验**：缺字段、类型错误、日期格式、`status` 取值、`pieces` 引用的作品编号不存在等都会逐条给出原因；非法记录不写入，合法记录照常生效。
- **冲突不覆盖**：展览编号 / 名称与现有数据或同批次重复、作品编号重复时，该条跳过并明确提示，绝不静默覆盖已有内容。
- **部分成功可见**：导入结束后列出每条记录的成功/失败原因；成功的记录立即出现在界面并写入 localStorage，刷新后保留。
- **文件级错误**：JSON 无法解析或顶层结构不对时整份文件拒绝，现有数据不变。

验证：`node scripts/verify-import.mjs`（分别用 `fixtures/import-valid.json` 合法文件与 `fixtures/import-partial.json` 混合文件检查全量导入、部分导入、冲突跳过与刷新持久化）。
