# 陶艺展览策划台

面向独立策展人的 Vue 3 展览编排工具。首屏直接进入策展工作面：创建展览草稿、选择作品并上线展览状态。

## 使用

```bash
npm install
npm run dev
npm run build
```

数据保存在浏览器 `pottery-exhibit-studio-v1` 命名空间。

## 作品展示顺序

已加入展览的作品在作品网格中置顶，可使用上移/下移按钮或拖拽卡片调整顺序；未加入的作品不参与排序。顺序只保存在该展览的 `pieces` 数组中（单一事实来源），实时写入 localStorage，刷新与切换展览后保持，且不改动作品档案、不影响其他展览里同一作品的编排。网格、展览详情、导览预览与 JSON 导出均从同一份顺序派生，工作面显示统一的顺序指纹，顺序异常会直接告警。

## 验证

```bash
npm run verify
```

覆盖：上移/下移/拖拽的纯函数性质与稳定性、实时持久化、刷新恢复、切换展览隔离、真实 DOM 交互，以及网格/详情/导览/导出四个入口的顺序一致性。
