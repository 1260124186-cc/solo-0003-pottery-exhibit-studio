# 陶艺展览策划台

面向独立策展人的 Vue 3 展览编排工具。首屏直接进入策展工作面：创建展览草稿、选择作品并上线展览状态。顶部提供全局搜索，可同时检索展览与作品并点击结果直达。

## 使用

```bash
npm install
npm run dev
npm run build
npm test
```

数据保存在浏览器 `pottery-exhibit-studio-v1` 命名空间。

## 全局搜索

- 一个关键词同时搜索：展览名称、副标题、策展人、作品标题、作者、材质；结果按“展览 / 作品”分组展示，并标注每条命中的字段。
- 输入即时搜索（200ms 防抖），回车或点击“搜索”立即执行；未输入有效关键词、搜索中、无结果分别有明确状态。
- 点击展览结果选中该展览并滚动到策展工作面；点击作品结果滚动到作品卡片并高亮。搜索本身只读取数据，不修改任何内容，也不改变当前选中的展览。
- 关键词归一化规则（同一关键词结果稳定可复现）：去除首尾空白（含全角空格等 Unicode 空白）；中间连续空白折叠为单个半角空格（不删除）；统一小写。被搜索字段按同一规则归一化后做包含匹配。
- 竞态处理：每次搜索分配单调递增序号，旧搜索的结果晚于新搜索返回时直接丢弃，不会覆盖当前结果。

测试覆盖：按六个字段分别搜索、无结果、输入归一化、快速连续输入竞态、结果跳转（`npm test`，38 例）。
