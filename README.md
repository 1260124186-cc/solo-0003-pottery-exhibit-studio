# 陶艺展览策划台

面向独立策展人的 Vue 3 展览编排工具。首屏直接进入策展工作面：创建展览草稿、选择作品并上线展览状态。

## 使用

```bash
npm install
npm run dev
npm run build
```

数据保存在浏览器 `pottery-exhibit-studio-v1` 命名空间。当前为初始化基线，测试将在后续任务中补充；构建命令覆盖三个工作流的生产烟囱检查。

## 观众导览预览

策展工作面右上角的「以观众视角预览」进入观众视角导览页（hash 路由 `#/preview/<展览id>`，刷新后仍停留在预览页）：

- 按作品加入展览的顺序逐件展示标题、作者、材质、年份、作品说明；页头显示展览名称、副标题与开放时间。
- 「上一件 / 下一件」逐件浏览，末件主按钮变为「回到第一件」，首件点「上一件」也会循环到末件；也支持键盘 ← →。
- 空作品展览显示「暂时无法开始导览」，不提供翻页操作。
- 每件作品可撰写一段观众可读的导览词，按作品 id 一一对应，保存在**独立**的浏览器命名空间 `pottery-exhibit-narratives-v1`，跨刷新保留。

导览词存储与策展数据完全隔离：预览功能不修改 `pottery-exhibit-studio-v1` 中的展览/作品结构与编排、上线流程。

端到端烟囱检查（需已 `npx playwright install chromium`）：

```bash
npm run build && npm run e2e:preview
```
