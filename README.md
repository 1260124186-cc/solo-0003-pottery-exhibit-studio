# 陶艺展览策划台

面向独立策展人的 Vue 3 展览编排工具。首屏直接进入策展工作面：创建展览草稿、选择作品并上线展览状态。

## 使用

```bash
npm install
npm run dev
npm run build
```

数据保存在浏览器 `pottery-exhibit-studio-v1` 命名空间（展览、作品、模板共用，刷新后恢复）。

## 展览模板与血缘

- 顶部「模板库」是独立的模板管理入口，可查看、编辑（自动生成新版本）、使用和删除；删除前有确认弹层。
- 在策展工作面可把任意展览的副标题、说明、策展人、展期与作品编排「保存为模板」。
- 从模板创建的每场展览都是**全新草稿**：内容经深拷贝带入，与模板没有任何共享引用；修改草稿不会改动模板。
- 模板在创建草稿之后再修改（版本递增）或被删除，已创建的草稿保持创建时版本不变；模板删除后草稿仍保留来源快照指纹。
- 草稿「创建副本」时血缘继续向上追溯模板，形成 **模板 → 草稿 → 副本** 三方引用链，在工作面的「血缘关系」面板实时校验：
  - `正常` 来源存在、快照一致、无共享引用；
  - `提示` 模板已升级/删除或草稿已独立改编（属正常编辑）；
  - `来源缺失 / 血缘损坏` 引用断裂、版本记录缺失或出现共享数组引用，任何一环改坏都可观察。

`npm run verify:lineage` 在 Node 下运行端到端验证（保存模板、创建草稿、副本、模板修改/删除隔离、刷新恢复、损坏可观察、旧数据迁移，共 40 项断言）。
