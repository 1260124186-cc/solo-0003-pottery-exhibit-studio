# 陶艺展览策划台

面向独立策展人的 Vue 3 展览编排工具。首屏直接进入策展工作面：创建展览草稿、选择作品并上线展览状态。

## 使用

```bash
npm install
npm run dev
npm run build
```

数据保存在浏览器 `pottery-exhibit-studio-v1` 命名空间。

## 删除草稿

仅“草稿”状态的展览可以删除；“预览中”与“已上线”的删除按钮禁用，工作面会说明原因（已进入审阅流程 / 已对公众发布）。

删除需要二次确认，弹窗列出清理范围；“取消”、Esc 或点击遮罩均不产生任何变化。确认后立即写入本地持久化，刷新后不会复活，并自动选中相邻的剩余展览。

关联数据生命周期：

| 数据 | 删除草稿时 |
| --- | --- |
| 展览本身、其空间编排、其导览文字 | 一并删除（按展览 id 精确级联） |
| 由它“复制为草稿”生成的其他草稿 | 保留为独立展览，仅清空来源标记 `copiedFrom`，其编排与导览不动 |
| 作品档案、其他展览及其编排/导览 | 一律保留，不受影响 |

旧版本只含 `exhibitions` / `artworks` 的存档会在载入时自动迁移：为老展览补齐空编排与默认导览，清理指向已删除展览的孤儿数据。

## 验证

```bash
npm test          # 领域规则 / 服务层持久化 / 组件交互（vitest + happy-dom，共 23 项）
npm run e2e       # 真实 Chromium 端到端（自动构建预览服务，共 11 项）
```

E2E 覆盖：删除草稿、取消删除（按钮/Esc/遮罩）、非草稿拒绝与原因、级联清理范围、副本保留、删除后刷新不复活、删空后的空状态。
