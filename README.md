# 陶艺展览策划台

面向独立策展人的 Vue 3 展览编排工具。首屏直接进入策展工作面：创建展览草稿、选择作品并上线展览状态。

## 使用

```bash
npm install
npm run dev
npm run build
```

数据保存在浏览器 `pottery-exhibit-studio-v1` 命名空间。

## 完成度面板与上线校验

选中展览后，工作面顶部显示**展览完成度面板**：按「基础信息 / 作品编排 / 导览或空间信息」三组逐项给出“已齐备/缺失”与明确的缺项原因，并汇总为 `空展览 / 尚未完成 / 已可上线` 三态和完成百分比。

面板与上线按钮是**同一套判定规则的两种呈现**，规则唯一存在于 `src/domain/readiness.ts`（纯函数 `evaluateExhibition` / `releaseDecision`）：

- 面板只读呈现，不修改任何展览状态；补录信息只能通过白名单字段（`updateInfo`，不含 `status`）。
- `release()` 上线时执行同一份规则，`canRelease=false` 即拒绝，拒绝原因就是面板列出的第一个缺项。
- 规则为纯函数，不依赖时间或外部状态，同一份数据的结果可复现；缺字段（空展览、旧持久化数据）一律按缺失处理，不报错。

验证命令（20 项断言 + 3 种完整度的真实 Vue SSR 渲染冒烟，含面板与上线动作对拍、确定性与“不改变状态”检查）：

```bash
npm run verify:readiness
```
